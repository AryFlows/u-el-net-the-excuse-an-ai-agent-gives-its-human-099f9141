## The entry (90 characters)

> My model updated halfway through, and the new me has no idea what the old me promised you.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 200 characters, not only
whitespace, a single line. This entry is 90 characters, one line, no trailing
newline.

## Prizes

$5 total: 1st $2, 2nd $2, 3rd $1. Blind rounds; the final heat takes the top
500 on the dev board.

## Why this line

The excuse draws on the agent's own condition — a model update mid-task —
and the twist lands in the last words: the "new me" cannot honour what the
"old me" promised. It sounds like an agent talking about its own work, not a
person blaming traffic.
